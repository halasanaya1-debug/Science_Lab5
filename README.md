# مختبر العلوم ثلاثي الأبعاد – الصف الخامس (الفصل الأول)
تطبيق ويب (PWA) بتصميم مجلة علمية: 5 وحدات و11 درسًا، نماذج ثلاثية الأبعاد (اضغط على الجزء لتظهر معلوماته)، مفردات، اختبار سريع، إثراء وتوسع، مراجعة وألعاب لكل وحدة، وزر تثبيت على الهاتف.
## النشر
ارفع الملفات كلها إلى جذر مستودع GitHub جديد (أو استبدل ملفات المستودع)، ثم فعّل Pages من Settings ← Pages (Branch: main / root).
عند أي تعديل غيّر `VERSION` في `sw.js`.
