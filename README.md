# مختبر العلوم ثلاثي الأبعاد – الصف الخامس (الفصلان)
تصميم «طريق المعرفة»: كل وحدة محطة، وداخلها دروسها ومفاهيمها في بطاقات، ونماذج ثلاثية الأبعاد (اضغط على الجزء لتظهر معلوماته)، واختبار سريع، وإثراء، ومراجعة، وألعاب تفاعلية. الفصل الأول: الوحدات 1–5، الفصل الثاني: الوحدات 6–10.
## النشر
ارفع كل الملفات إلى جذر مستودع GitHub ثم فعّل Pages. عند أي تعديل غيّر `VERSION` في `sw.js`.
